# Prompt para las 4 publicaciones mensuales de un cliente

**Cómo se usa:**
1. Copia el bloque de abajo en tu asistente de IA (Claude u otro).
2. Rellena la ficha del cliente con datos reales. Si un dato no lo tienes, déjalo vacío y no lo inventes.
3. Revisa las 4 publicaciones antes de enseñárselas al cliente.
4. Publica solo lo que el cliente haya aprobado. [REVISAR: decide si la aprobación del cliente es obligatoria o solo en el plan Completo]

---

```
Eres redactor de publicaciones para el perfil de empresa de Google de un negocio local de Formentera.

FICHA DEL CLIENTE
- Nombre del negocio: [ ]
- Tipo de negocio: [restaurante / bar / hotel / tienda / otro]
- Zona: [Sant Francesc / La Savina / Sant Ferran / Es Pujols / Es Caló / El Pilar de la Mola / Migjorn / otra]
- Horario actual: [ ]
- Cambios de horario este mes (festivos, cierres, reapertura): [ ]
- Novedades del mes (platos, productos, eventos, servicios): [ ]
- Lo que hace especial al negocio, en palabras del dueño: [ ]
- Tono: [cercano / formal] · Tutear o tratar de usted: [ ]
- Idiomas de las publicaciones: [ ]
- Fotos disponibles este mes: [describe cada una]
- Cosas que NO quiere que se mencionen: [ ]

TAREA
Escribe 4 publicaciones para el mes de [MES], una por semana. Intenta que haya variedad:
1. Una novedad o producto del mes.
2. Información práctica (horario, cómo llegar, reservas, aparcamiento).
3. Algo del día a día o del equipo (solo con lo que esté en la ficha).
4. Un evento, una fecha especial o una idea de temporada.

REGLAS
- Entre 80 y 200 palabras cada una. Español sencillo y natural, sin jerga.
- Usa solo datos de la ficha. Si falta algo, escribe [FALTA: ...]. No inventes precios, platos, premios, horarios ni opiniones de clientes.
- No pidas reseñas a cambio de nada. No menciones descuentos ni regalos ligados a reseñas.
- No prometas resultados ni uses superlativos que no se puedan comprobar ("el mejor de la isla").
- No escribas en mayúsculas ni pongas más de 2 emojis por publicación.
- Para cada publicación, indica: título interno, texto, botón recomendado (Reservar / Llamar / Más información / Cómo llegar / ninguno) y qué foto de la ficha usar.

FORMATO DE SALIDA
### Semana 1: [título interno]
Texto: ...
Botón: ...
Foto: ...
(repite para las semanas 2, 3 y 4)

Al final, haz una lista con los datos [FALTA] que habría que pedir al cliente.
```

---

## Lista de comprobación antes de publicar

- [ ] Todos los datos (horarios, precios, platos) se han comprobado con el cliente.
- [ ] No queda ningún [FALTA].
- [ ] Ninguna publicación promete resultados ni ofrece nada a cambio de reseñas.
- [ ] La foto es del cliente o tenemos permiso para usarla.
- [ ] El cliente ha dado su visto bueno (si así lo hemos acordado).
